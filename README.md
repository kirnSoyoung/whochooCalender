# 🐶 후추 Todo & Calendar

반려견 후추의 사진과 게이미피케이션 요소를 결합한 웹 기반 **할 일(Todo) 관리 및 캘린더 서비스**입니다.  
사용자의 목표 달성을 자연스럽게 유도하고, 지속적인 동기부여를 제공하는 데 초점을 맞춰 개발되었습니다.

---

## ✨ 프로젝트 개요

본 프로젝트는 반려견 '후추'의 사진을 활용하여  
**보상 기반의 동기부여 시스템**을 적용한 일정 관리 웹 서비스입니다.  
할 일을 완료할 때마다 후추의 다양한 사진을 모을 수 있어  
사용자가 매일 서비스를 찾게 되는 경험을 제공합니다.

---

## 🎯 핵심 특징

### ✔ Local Storage 기반 데이터 영속성
- 할 일 목록  
- 캘린더 일정  
- 획득한 후추 사진 목록  
- 뽑기 재화(코인 등)  
위 데이터가 모두 Local Storage에 저장되어 새로고침 또는 재접속 시에도 유지됩니다.

---

### 🎁 연속 보상 & 뽑기 시스템
- 할 일 완료 카운터와 이미지 인덱스를 **동기화**하여 보상이 자연스럽게 이어지도록 설계  
- 직접 구현한 확률 기반 뽑기 로직 적용  
- 사용자에게 수집의 즐거움을 제공하는 보상 구조

---

### 🎬 동적 UI & 애니메이션
- 뽑기 페이지에 애니메이션을 적용하여 사용자 재미 요소 강화  
- 확률 처리, 애니메이션 타이밍 조절 등 반복적인 시행착오를 거치며  
  **동적 UI 설계의 중요성**을 깊이 이해

---

## 📝 요약

이 프로젝트는 단순한 Todo 웹앱을 넘어,  
**반려견 사진 + 보상 시스템 + 일정 관리**가 결합된 감성형 서비스입니다.  
데이터 흐름 제어, 확률 로직, Local Storage 활용 등  
웹 개발의 핵심 요소들을 직접 설계하며 역량을 강화했습니다.
